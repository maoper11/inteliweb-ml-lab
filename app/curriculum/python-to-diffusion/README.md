# From Python to Diffusion Models

Ruta principal de Inteliweb ML Lab.

## Objetivo

Llevar al estudiante desde conceptos básicos de Python hasta comprender los fundamentos de los modelos de difusión y su relación con ComfyUI.

## Primera versión: 15 notebooks

1. `00_Bienvenida.ipynb`
2. `01_Verificar_Entorno.ipynb`
3. `02_Python_Variables.ipynb`
4. `03_Python_Listas_Diccionarios.ipynb`
5. `04_Python_Funciones.ipynb`
6. `05_NumPy.ipynb`
7. `06_Imagenes_como_Numeros.ipynb`
8. `07_AI_ML_Deep_Learning.ipynb`
9. `08_Clasificacion.ipynb`
10. `09_Perceptron.ipynb`
11. `10_Tensores_PyTorch.ipynb`
12. `11_Primer_Modelo_PyTorch.ipynb`
13. `12_GPU_CUDA_VRAM.ipynb`
14. `13_Pillow_OpenCV.ipynb`
15. `14_Introduccion_a_Difusion.ipynb`

Todos los notebooks están en español, utilizan el kernel `Python - Inteliweb ML Lab` y combinan conceptos cortos, celdas ejecutables, ejercicios y conexiones con ComfyUI.

## Instalación

Durante `Install` o `Update Packages`, las lecciones se generan en:

```text
app/curriculum/python-to-diffusion/notebooks
```

y se copian sin sobrescribir el progreso del estudiante hacia:

```text
app/workspace/courses/python-to-diffusion/notebooks
```

Abre primero `00_Bienvenida.ipynb` desde JupyterLab.

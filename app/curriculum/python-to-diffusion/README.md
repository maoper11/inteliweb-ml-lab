# From Python to Diffusion Models

Ruta principal de Inteliweb ML Lab.

## Objetivo

Llevar al estudiante desde conceptos básicos de Python hasta comprender y ejecutar pipelines de modelos de difusión, relacionando el código con conceptos utilizados en ComfyUI.

## Módulos previstos

1. Primeros pasos con Jupyter y el entorno.
2. Fundamentos de Python.
3. Datos, NumPy, imágenes y matemática esencial.
4. Machine learning clásico.
5. PyTorch, entrenamiento y GPU.
6. Computer vision.
7. Autoencoders, espacio latente y difusión.
8. Optimización de GPU y memoria.
9. Equivalencia entre código Python y workflows de ComfyUI.

Los notebooks se agregarán dentro de `modules/<module-slug>/`.
